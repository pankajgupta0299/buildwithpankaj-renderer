# Reel 06 · Movie Pitch Machine

## What the Reel teaches

Build a one-page movie pitch generator with an AI coding assistant. It takes a simple situation and shows two original fictional pitches, one with a colorful musical mystery treatment and one with a night thriller treatment. The UI shown in the Reel is an illustrated representation of the provided working starter.

## Try the starter

From the repository root, run `python3 -m http.server 8000`, then open `http://localhost:8000/reel06/`. The app requires no account, API key, or external assets. Type another situation and press **Make the movies**. The starter uses deterministic story templates; it does not call a generative model at runtime. Adapt `model.mjs` to change the storytelling rules.

## Starter prompt for the audience

> Build a mobile-friendly movie pitch generator in HTML, CSS, and JavaScript. Show an input where someone can type an everyday situation, a “Make the movies” button, and two visually different cards labeled Bollywood and Hollywood. Each card needs an original title, genre, one-sentence plot, and visual motif. Use fictional characters and original stories; do not use real film stills, copyrighted titles, or celebrity likenesses. Begin with transparent local story templates that work without an API key. Make the button update both cards for a new input. Keep the page accessible and usable on a phone.
