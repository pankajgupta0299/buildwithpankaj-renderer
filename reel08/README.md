# Reel 08 — Movie Mashup

An original, working mobile demo. Select a supported genre pair and tap **MAKE MY MOVIE** to reveal a fictional title, plot and twist. The three samples are predetermined, not generated by AI at runtime. The artwork is an original AI-generated fictional poster image, with no celebrity or film IP.

Run from repository root: `python3 -m http.server 8000`, then open `/reel08/`.

## Copyable build prompt

> Build a mobile-first one-page Movie Mashup game in plain HTML, CSS and JavaScript. Let the viewer choose from three fictional genre pairs: Shaadi × Horror, Romance × Sci-fi and Mystery × Comedy. On button tap reveal one original fictional movie title, one-sentence plot and funny twist from a small local data object. Provide a Try Another button. Make the first example “Bhoot Ki Baraat”: the groom arrives at a wedding, but the wedding party are century-old ghosts; the bride is secretly a ghost hunter. Use readable type, dark charcoal and olive accents, and a large poster area. No API keys, no copyrighted film posters, no real actor likenesses. Add a visible note explaining that the preset examples are sample data, not live AI output. Return complete HTML, CSS and JavaScript plus simple local run steps.
